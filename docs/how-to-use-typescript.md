# How to use TurboCommons with TypeScript

Install the package from npm:

```bash
npm install turbocommons-ts
```

Import the utilities you need:

```typescript
import { StringUtils } from 'turbocommons-ts';

const n = StringUtils.countWords('word1 word2 word3');
```

The package source and build instructions are available in
 [`packages/turbocommons-ts`](../packages/turbocommons-ts/).
