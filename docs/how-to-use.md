# How to use TurboCommons

TurboCommons provides the same common development operations across multiple
programming languages. Select the package you want to use:

- [C#](how-to-use-csharp.md)
- [Java](how-to-use-java.md)
- [JavaScript](how-to-use-javascript.md)
- [PHP](how-to-use-php.md)
- [Python](how-to-use-python.md)
- [Shell scripts](how-to-use-shell.md)
- [TypeScript](how-to-use-typescript.md)

Node.js usage is documented with [JavaScript](how-to-use-javascript.md), since
the Node.js package is the TypeScript package consumed through CommonJS.
